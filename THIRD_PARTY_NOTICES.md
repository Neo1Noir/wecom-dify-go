# Third-party dependencies

The middleware's own source code is MIT licensed. It uses `modernc.org/sqlite`, a pure-Go SQLite implementation, and the transitive modules pinned in `go.mod` / `go.sum`. These dependencies retain their own copyright and license terms.

No third-party source or binary packages are copied into this repository. When distributing compiled binaries or images, retain the applicable dependency notices. The SQLite implementation and its notices are maintained at [modernc.org/sqlite](https://pkg.go.dev/modernc.org/sqlite). Container base images also retain their upstream terms.
